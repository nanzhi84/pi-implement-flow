# 本机控制权与独立 Agent 上下文

按 Spec #1，不新增执行账本；采用按 GitHub 数字仓库 ID、同一 OS 用户标识的本机 Unix socket 作为临时独占控制权，避免仅锁 `.git` 导致不同 clone 重复编排。残留 socket 不自动抢占，必须核对原进程；分支、worktree、未提交代码和远端证据仍是接续事实，而非可丢弃缓存。

核对 pi 0.87.1 的 SDK 与实际行为后，角色使用独立 SDK 会话、显式工具/指令和不进行自动发现的 ResourceLoader；不沿用父会话的扩展、技能或对话。相较继承用户配置启动 CLI，这让角色配置可检查、取消可等待，但同一进程和 OS 凭据不构成安全沙箱，也不能替代 GitHub 原生 required review 的不同批准身份。

项目命令只在用户确认后的隔离 worktree 与独占资源目录中运行，并按 POSIX 进程组取消；无法确认停止时保留控制权和现场。T1 对尚未支持的保护规则安全拒绝；T2 未交付时，成功启动仅进入明确的安全暂停，不绕过后续门禁。
